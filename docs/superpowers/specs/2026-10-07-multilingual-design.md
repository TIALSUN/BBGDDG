# BBGDDG 三语支持设计

日期：2026-10-07。目标版本：1.3.0。

## 用户目标与已确认范围

用户要求为项目所有用户可见内容增加英文和日文选项，并明确包含 GitHub README 和主要使用文档。保留中文和当前深色视觉风格。此前已授权每轮通过验证后自动提交、推送到 TIALSUN/BBGDDG，以及正式发布时更新发行包和桌面固定入口。

成功标准是完整的中文、英文、日文体验，而非只翻译首页或新增一个没有完整翻译内容的下拉框。文献、项目名称、笔记正文、原文引用以及已有 AI 对话属于用户内容，保持原文。

## 语言选择与状态

统一使用 `zh-CN`、`en`、`ja`。设置页提供“中文 / English / 日本語”，同时在登录入口提供语言切换。默认中文，首次显示及重启后的界面使用已保存的选择。切换界面语言时保留未保存草稿、阅读位置、问答状态及当前路由。

在现有 `ui-preferences.json` 中扩展界面语言和 AI 回答语言；旧文件缺少新字段时补齐默认值，保留原有阅读工具收起设置。保存采用现有原子写入，并合并字段，避免语言设置与阅读设置互相覆盖。保存失败明确提示，保留当前选择并提供重试，不显示虚假的已保存状态。

界面语言设置与 AI 回答语言分开。AI 回答语言支持自动、中文、英文和日文；默认自动，由问题与上下文决定。显式选择时作为回答语言指令传入请求，不改写引用或历史对话。预设提问按界面语言显示。

## 翻译架构

采用统一消息键及三套本地翻译资源，不通过扫描或替换 DOM 翻译，不调用外部翻译服务。消息参数支持页码、数量、路径和模型名称等动态内容。编译或测试检查三语键一致及参数一致，避免某个语言遗漏按钮或提示。

前端使用语言上下文与统一翻译函数；桌面和服务端复用同一消息规范与资源，并由构建流程明确携带对应文件。日期、相对时间、数字与数量文案使用所选语言的格式。同步更新 HTML `lang`、辅助标签、工具提示、占位文本和页面标题。

保持现有页面结构与深色样式。语言选项用原生可访问选择控件，覆盖键盘焦点、英文长度及日文换行；手机抽屉、平板分屏和桌面阅读页均检查溢出。

## 必须覆盖的运行界面

- 项目首页、搜索、新建/删除项目、最近项目和导航。
- 项目文献、文件夹、子文件夹、导入、论文搜索、网页提取与管理弹窗。
- PDF 工具栏、页码、缩放、高亮、注释、原文跳转与选文菜单。
- 项目/文献笔记、独立复习、标签、Markdown 预览、引用、草稿及保存失败提示。
- AI 选择、配置、连接测试、余额/用量、问答范围、记忆、摘录、引用及相关文献。
- 登录、全局错误、空状态、加载状态、确认弹窗、日期和辅助标签。
- Electron 启动页、原生菜单、关于窗口、关闭未保存内容提醒和启动/服务错误。
- CLI 帮助、操作结果与错误，通过语言参数或环境变量选择语言；机器可读 JSON 字段保持稳定。
- Windows 安装器提供中文、英文和日文语言资源；语言选择方式按安装器可用配置验证。

桌面启动时直接读取本地设置；运行中的语言修改通过受限的后端/主进程通知更新菜单，继续保留渲染隔离与本机会话鉴权。不得为了语言同步向渲染层开放任意 Node 或文件访问。

服务端自有用户错误与状态使用统一消息键，依据请求语言返回或由前端本地化。第三方服务返回的原始内容保留并搭配本地化提示，不假装已经完成准确翻译。语言参数不得改变数据访问边界或暴露内部凭据。

## README 与主要文档

提供 `README.md`（中文）、`README.en.md` 和 `README.ja.md`，顶部互相链接。三语对应相同功能范围、下载入口、安装步骤、AI 配置说明、数据位置、安全说明和移动版限制。

主要用户文档包括桌面构建与运行说明、移动路线图、安全/隐私说明和发布说明；新增英文、日文版本并互相链接。上游许可和作者声明保留原始法律文本与来源链接。内部历史设计和历史测试日志不是用户手册，不逐篇翻译，但最新版验证记录提供三语摘要。

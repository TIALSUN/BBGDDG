# BBGDDG 1.3.0 桌面发布计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. This release packages already reviewed application features; it does not add an independent offline iPad app.

**Goal:** 将 feat/ui-ipad 已完成的功能发布为 Windows 桌面 1.3.0，更新用户现有固定入口并同步 GitHub Release。

**Architecture:** 复用 Electron + 自带 Node + 本机 Fastify / SQLite。先准备独立构建产物，在隔离数据目录运行打包与安装验证，最后复制完整 win-unpacked 到 outputs/current。个人文献、笔记与账号数据独立于程序目录，不复制或清空。

**Tech Stack:** Node 24, Electron 44.5.1, electron-builder 26.0.12, NSIS, Playwright。

**Spec:** 用户“更新桌面版”、AGENTS.md 发布与数据保留约定，以及 docs/superpowers/specs/2026-10-11-bbgddg-ui-ipad-design.md 的已实施桌面功能。

## Global Constraints

- 保持已批准的 feat/ui-ipad 工作区；main 保留，发布标签指向实际验证提交。
- 版本号 1.3.0；若远端已存在此版本则先检查内容，不能覆盖既有发布。
- 个人数据 `%APPDATA%/BBGDDG/data` 不能清空；升级自动备份。
- 程序有未保存内容时等待正常关闭，不能强制终止用户进程。
- 固定入口使用完整 win-unpacked；桌面单一 BBGDDG.lnk 指向 outputs/current/BBGDDG.exe。
- 只能推送 origin TIALSUN/BBGDDG；发布实际 EXE、Portable.zip 和 SHA-256，不提交二进制和个人数据到 Git。
- 网络或自动审批阻塞时先完成可行的本地构建，准确记录尚未完成的同步。

## Review Focus

- 安装包真实运行、原生 SQLite / PDF 依赖完整。
- 笔迹写入、重启、标注导出与备份在打包环境工作。
- 原有多格式导入和 AI 加密设置回归。
- 固定入口覆盖前程序关闭；个人数据摘要保留，实际升级只允许正常迁移并生成备份。
- Release 标签、版本、文件校验与已测试产物一致。

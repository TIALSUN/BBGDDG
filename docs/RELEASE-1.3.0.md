# BBGDDG 1.3.0 · 工作区与手写标注

Windows x64 桌面更新，加入统一研究工作区，以及 PDF 和笔记的可编辑手写。

- 文献、笔记、标注和 AI 导航统一，保留搜索与阅读上下文。
- 钢笔、荧光笔、划线、整笔擦除、套索选择、复制、移动、缩放与撤销重做；支持鼠标输入。
- 笔记支持空白、横线、方格手写区，延长纸张并调整顺序。
- 选中文字添加高光或下划线，区域摘录保存为带来源的图片笔记。
- 手写草稿恢复、版本冲突副本；修复旧窗口保存响应覆盖新草稿的问题。
- 导出带标注的 PDF 副本，打印文字与手写混合笔记，备份并恢复可编辑笔迹。

下载 `BBGDDG-1.3.0-Setup.exe` 安装，或完整解压 `BBGDDG-1.3.0-Portable.zip` 后运行 `BBGDDG.exe`。SHA-256 校验值随包提供。安装包尚未进行发布者数字签名。

更新保留文献、笔记、阅读进度和账号设置；数据库从 schema 10 增量升级至 11，升级前自动备份。文字笔记仍需点击保存，手写独立自动保存。并行编辑同一笔记时，旧窗口可能提示保留副本并重新打开。

此发布是 Windows 桌面版。iPad 真机 Pencil、系统打印与“文件”往返仍待验收；独立离线 iPad 应用和跨设备同步未包含在本次发布中。

验证：构建成功，后端 103 项、浏览器 71 项；实际打包程序的 PDF、高光、MD/TXT/DOCX、AI 模拟接口和加密设置回归通过。旧版隔离数据升级、自动备份、手写重启保留、PDF 导出和可编辑备份恢复通过。详细记录见仓库 `docs/VALIDATION-1.3.0.md`。

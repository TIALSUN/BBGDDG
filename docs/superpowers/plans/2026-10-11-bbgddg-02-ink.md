# BBGDDG iPad 手写与 Pencil Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 PDF 和笔记中提供可恢复、可编辑的手写以及文字、笔迹和图像选择。

**Architecture:** 采用独立版本化 ink 文档和乐观并发控制，原 PDF 与 Markdown 不直接修改。SVG 渲染页面叠层及手写块，使用 Pointer Events 收集笔迹；先验证性能，超过预算再替换渲染层，存储格式保持不变。

**Tech Stack:** 现有 React、PDF.js、TypeScript、Fastify、SQLite；IndexedDB 保存待上传草稿。首轮不用 PencilKit。

**Spec:** `docs/superpowers/specs/2026-10-11-bbgddg-ui-ipad-design.md`；前置计划 `2026-10-11-bbgddg-01-workspace.md`。

## Global Constraints

- 保留现有文献、笔记、标注、阅读进度和 AI 配置。
- 数据库升级前备份，采用增量迁移，不清空个人数据。
- 默认 Pencil 书写、手指浏览、双指缩放；可显式开启手指绘制。
- 手写自动保存，显示保存中 / 已保存 / 失败待重试；保留本机待保存数据，失败后可恢复。
- 文字笔记继续明确点击保存。
- 压力缺失时使用固定粗细。
- PDF 原始文件不直接修改。
- 桌面浏览器模拟不能替代 Pencil 真机验收。

## Review Focus

- 页旋转、裁切框、缩放使笔迹错位：任务 1、3。
- pointercancel、多指切换留下跨页飞线：任务 2。
- 服务重启、离线、并发修改误报保存成功：任务 1、4。
- 扫描 PDF 无文本层时不能误选空文字：任务 5。
- 旧笔记、旧标注和新手写共存，孤立附件不泄露：任务 1、6。

## 数据及文件边界

新建 `src/core/ink-types.ts` 定义共享序列化模型、`ink.ts` 管理数据；`src/server/ink-routes.ts` 管理路由；`frontend/src/ink/` 存放几何、输入、历史、草稿、Canvas、Toolbar。前端以 type-only import 共享 ink-types，不导入服务器实现。

`InkPoint={x:number,y:number,pressure?:number}`；`InkStroke={id:string,tool:'pen'|'marker'|'line',color:string,width:number,points:InkPoint[]}`；`InkBlock={id:string,height:number,background:'blank'|'ruled'|'grid',strokes:InkStroke[]}`；`InkTarget={kind:'pdf',sourceId:string,page:number,contentHash:string}|{kind:'note',noteId:string}`；`InkDocument={version:1,revision:number,target:InkTarget,blocks:InkBlock[]}`。

PDF block 坐标为 PDF 原始页面坐标，笔记 block 宽固定 1000 逻辑单位，height 同单位。颜色只允许项目调色板，宽度 0.5–32，坐标和压力必须有限，pressure 为 0–1；每文档 JSON 上限 8 MiB、笔画上限 10000、每笔最多 20000 点。超限明确失败并保留草稿，不静默丢点。

## Task 1: 增量迁移与 ink API

- [ ] 执行 `node --import tsx --test test/integration/ink.test.ts test/integration/database-migration.test.ts`，确认 ink 能力缺失。

- [ ] 实现坐标变换与命令历史；默认最多 100 个命令，丢弃最旧历史不删除画布内容。
- [ ] 实现输入协调：pointer capture、pointercancel、跨页终止、笔与触控分工；压力不可用采用固定宽度。

- [ ] 添加测试：绘制→缩放→旋转后页面坐标保持一致；多页不串页；整笔橡皮擦可撤销；隐藏叠层不修改已存数据。
- [ ] 执行 ink-reader，确认工具尚不存在。
- [ ] 实现 InkCanvas 与 Toolbar，在每个 PDF Page 内接入；浏览及文字选择模式让事件到达原文层，绘制模式仅拦截画布输入。
- [ ] 添加工具栏位置和左手选项，触控目标满足 44 像素；保持手势滚动和缩放路径可用。

## Task 4: 自动保存与本机恢复

**Files:** 新建 `frontend/src/ink/{draft-store,useInkDocument}.ts`；接入 ReaderPage；测试 `frontend/e2e/ink-recovery.spec.ts`。

**Interfaces:** `useInkDocument(projectId:string,target:InkTarget):{document:InkDocument,status:'saving'|'saved'|'pending'|'conflict',apply:(command:InkCommand)=>void,retry:()=>void}`；IndexedDB key 含 projectId、target、version；保存草稿包含 baseRevision、localSequence、document，不含会话口令或 AI 密钥。

- [ ] 添加测试：500ms 防抖期间刷新可恢复；PUT 失败状态为 pending；旧请求返回不能覆盖新画；409 后保留本机与服务器两份版本，不自动覆盖。
- [ ] 执行 ink-recovery，确认尚无恢复能力。
- [ ] 实现先写 IndexedDB 后上传的串行队列、500ms 上传防抖、重试与冲突副本保留；本机存储失败时明确提示，不能声称草稿已保留。
- [ ] 接入保存状态；页面离开时立即写本机，不依赖卸载时网络请求；服务器确认并且无更新草稿后才标 saved。
- [ ] 执行恢复测试和源删除测试；提交 `feat: recover unsaved ink and surface conflicts`，推送 origin。

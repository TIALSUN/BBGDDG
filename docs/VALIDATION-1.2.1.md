## 发现的问题

- GitHub `main` 已包含启动修复，但旧 `v1.2.0` 标签仍指向修复前的 `f44cbef`。

## 修复与验证

- Windows 原生模块在隔离运行目录中实际加载成功；打包脚本检查必需的 `.node` 文件。
- 最终安装包解包后、实际安装到测试目录后、便携 ZIP 解包后，以及桌面固定入口，均通过桌面流程测试：启动本地服务、PDF 导入、高亮位置、笔记持久化、取消高亮、会话鉴权、渲染隔离及正常关闭后端。未发现页面错误。
- ZIP 生成脚本执行成功，最终压缩包完整性检查通过。
- 打包脚本语法检查与 Git 差异检查通过。此次不改变阅读/笔记业务逻辑，沿用 1.2.0 已有回归；新增 GitHub Windows 桌面打包及启动流程检查。
- 发布时核对 GitHub 资产名称、大小及 SHA256，提供独立校验文件。

# BBGDDG 1.3.1 · 紧凑阅读顶部

参考用户提供的知云阅读布局，修复收起顶部后仍占用过多阅读空间的问题。

- 收起后采用标题栏＋阅读工具栏：标题栏 49px，PDF 工具栏 53px，AI 选择并入标题栏。
- 阅读／批注分开；阅读时隐藏手写设置，进入批注时展开一行工具，更多设置在工具行内横向滚动。
- 缩放、页码输入、上一页／下一页和导出集中在同一行。顶部图标保留可访问名称与操作提示。
- iPad 和窄屏保留 44px 触控面积，长文献名与模型名按可用宽度收缩。
- 切换布局保留当前文献、笔迹和设置；回到阅读模式会退出绘制状态。

完整浏览器回归 74 项通过，包含 1440、1024、390px 的高度与溢出检查，以及手写重启、页码导航和导出对话框。Windows 打包与固定入口的实测结果见仓库 `docs/VALIDATION-1.3.1.md`。

下载 `BBGDDG-1.3.1-Setup.exe` 安装，或完整解压 `BBGDDG-1.3.1-Portable.zip` 后运行 `BBGDDG.exe`；SHA-256 校验文件随包提供。更新保留本机文献、笔记和账号设置。

本次为 Windows 桌面更新；iPad 独立离线应用和跨设备同步未包含在此次发布中。安装包尚未进行发布者数字签名。

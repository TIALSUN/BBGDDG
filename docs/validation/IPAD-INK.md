# iPad 手写验证记录

日期：2026-10-11。开发分支：feat/ui-ipad。当前为待真机验收的开发版本，不是正式 iPad 发布。

## 设备与访问

用户设备：用户描述为“最新款 Air，11 英寸”。具体代次、iPadOS、Safari 与 Pencil 型号尚未确认。
真实设备不在当前执行环境，以下真机项目均未验证：Pencil 连续书写延迟、手掌误触、手指滚动、双指缩放、旋转、软键盘、系统分屏、中断恢复、保存到“文件”再导入。
服务保持原有本机监听与会话认证。未开放局域网或公网端口；跨设备安全访问方式仍待确定。

## 已有自动验证证据

- UI：390 / 820 / 1024 像素代表性窗口，工具切换保留草稿、窄屏抽屉焦点、复习原文切换、导航及搜索状态。
- 增量升级：schema 10 → 11，升级前数据库备份包含旧笔记，旧正文保持不变。
- PDF：native PDF 坐标保存，缩放、重载不改变坐标；缩放撤销问题由新回归测试发现并修复。
- 笔记：手写块与 Markdown 共存，空白 / 横线 / 方格、延长纸张、套索复制 / 移动 / 缩放 / 删除、整笔擦除及撤销。
- 恢复：失败待重试、刷新恢复、本机与服务器冲突副本、明确采用服务器版本；已保存缓存不遮蔽服务器的新版本。
- 选区：显式 Pencil 文字工具，选字后仍需用户点击高光 / 注释 / 提问；单页 PNG 区域摘录、来源引用、跨项目拒绝访问、笔记删除清理无引用图片。
- 导出：pdf-lib 1.17.1 MIT，原文件 hash 不变、页数不变、旋转和 CropBox 保留；旋转裁切 fixture 栅格化校验标记位置及透明度，见 pdf-export-rotation.png。
- 笔记打印：中文、KaTeX、SVG 手写进入同源打印页，使用系统“存储为 PDF”；最终打印分页及字体需真机复核。
- 备份：含笔记、标注、可编辑笔迹及图片，不含原 PDF、密钥或数据库。重复恢复去重，错误路径、版本、校验及缺失引用拒绝，事务失败回滚。
- 性能：Chromium 桌面、1000 笔 × 100 点；单独运行 p95 4.80 ms，完整回归并发运行 p95 9.90 ms。仅测量活动输入到下一帧，不包含 Pencil 硬件延迟，也不是 iPad 性能认证。

## 实施决策与限制

1. 复用既有 SQLite / Fastify / React，新增 ink 文档，不修改原 PDF 或 Markdown。
2. 图片存 SQLite BLOB，避免裸文件路径；代价是数据库备份增大。
3. 几何引擎以纯 Node 测试代替浏览器动态导入，交互另用真实 Chromium E2E。
4. 备份 ZIP 使用 stored 条目，恢复仅接受本应用格式、不接受外部重新压缩的文件；限制压缩包 100 MiB、条目 10000、单图片 5 MiB，并校验 CRC / SHA-256 与结构。无需向文件系统解压，事务直接写 BLOB。代价是备份文件较大及外部重压缩不兼容。
5. 缺失原文的 PDF 手写恢复为独立笔记副本，保留原来源 ID / hash 提示，坐标转为笔记画布；不绑定另一份文献。代价是需重新导入原文后人工核对。
6. 首轮绘制使用选定固定粗细；压力值保存于笔迹中。真实压力笔刷、局部擦除、OCR、手写识别、形状辅助及高级 Pencil 操作均未宣称交付。
7. IndexedDB 是当前浏览器的待同步草稿存储，不等同完整离线文献库或跨设备同步。
8. 当前桌面固定入口及 Release 未替换。开发分支保留，真实设备验收另行进行。

## 最终验证与审查修复

2026-10-11 最终构建 `npm run build` 成功；`npm test` 103 / 103，覆盖率门槛通过（行 89.29%、分支 78.80%）；`npx playwright test` 71 / 71（1.1 分钟）。本轮桌面输入帧基准 p95 9.40 ms。构建仍提示主 JS chunk 大于 500 kB，未将桌面结果当作真实 iPad 性能。

独立审查给出 2 项 Critical、4 项 Important，全部纳入同一轮修复；没有 Minor。未进行第二次独立审查，也不将修复后自动验证表述为审查者再次批准。

| 审查问题 | 修复与证据 |
| --- | --- |
| 旧窗口响应覆盖新草稿 | IndexedDB 事务内检查 owner / sequence；旧写入不能覆盖新草稿或清除其 pending。跨窗口实际复现：刷新后 2 块变 1 块；修复后仍为 2 块。旧窗口的新修改保留为冲突副本，并提供下载入口。 |
| stored ZIP 分配绕过上限 | 解包前检查 stored 两种长度一致、真实累计大小、目录和本地头一致、数据边界及条目不重叠；恶意大小测试通过。 |
| 接受远端后撤销旧状态 | 重置 history / redo 基线，并重新挂载画布清除选区；不刷新冲突页即可复现 blank 覆盖 grid，修复后撤销仍保留 grid。 |
| 归档收据导致错误去重 | 按实际仍存在的笔记、标注、图片内容及恢复笔迹副本去重；删除后可重新恢复；新增笔记的快照不会重复旧高光或图片；缺原文及冲突恢复副本也逐项去重。 |
| 越界标注进入数据库 | 校验映射来源类型、实际页数、声明引用及正向矩形；第 999 页和反向矩形原子拒绝。 |
| 摘录失败残留图片 | 图片、笔记和 ink 在同一事务创建；数据库触发器模拟关联失败，三张表均无残留。备份仅导出有效引用图片，恢复也仅导入有效引用图片。 |

回归文件：`frontend/e2e/ink-recovery.spec.ts`、`ink-selection.spec.ts`，`test/integration/ink-backup.test.ts`、`ink-excerpt.test.ts`。部分补充测试在实现之后加入，不宣称所有代码遵循完整测试先行流程。

保留的边界：最新打开的窗口获得该目标的本机草稿写入权；旧窗口提示保留并下载副本后重新打开。该机制保护草稿，尚不提供多窗口同时合并笔迹。未清理旧版本已经留下的附件数据；新的备份排除无引用附件。

## 全部实施裁定

按作出顺序记录，包含原因与判断错误时的代价：

1. 原生 worktree 工具无法解析嵌套仓库，改用相邻 Git worktree 保持隔离；代价：手动维护生命周期。
2. UI 共享样式任务 2–5 合并提交；代价：单次审查范围较大。
3. 文件夹上下文保存展开 ID，匹配现有树形界面；代价：未来筛选模型变化时需调整。
4. 几何与历史使用纯 Node 测试，DOM 交互另测；代价：引擎测试本身不覆盖浏览器。
5. 附件使用 SQLite BLOB，避免文件路径；代价：数据库备份更大。
6. 重叠实施相互依赖的任务，以端到端保存路径验证；代价：单次差异较大。
7. 仅支持本应用 stored ZIP，避免外部压缩格式与文件系统解包；代价：文件较大，外部重新压缩不兼容。
8. 缺失 PDF 的笔迹恢复为可编辑笔记，保留来源 ID / hash；代价：原文需重新导入后人工核对。
9. 手写与导出计划合并为一次实施和审查；代价：审查范围较大。
10. Windows 直接执行等价验证并手动记账，替代 Bash 包装脚本；代价：记录需要人工核对。
11. 部分补充回归在实现之后加入，明确保留流程证据限制；代价：测试先行的证明较弱。
12. 草稿写入权采用事务内 owner / sequence 比较，保护跨窗口和重新挂载；代价：旧窗口需要下载副本并重新打开，不自动合并并行修改。
13. 真机 Pencil、手掌误触、系统手势、打印和“文件”往返保持待验收；代价：当前不能作为正式 iPad 发布。
14. 跨设备访问仍保持原有本机监听和认证；代价：尚不能直接从 iPad 连接 Windows 服务。
15. 外部重压缩 ZIP、压力笔刷、PencilKit、完整离线同步继续按已确认范围延期；代价：首轮不包含这些能力。

Deferred minors：无。

# 1.2.0 实施计划

2026-10-07：用户授权按已整理设计修改，并将最新版上传到其 GitHub。

1. 项目首页与项目工作区：紧凑 AI 入口、最近项目、设置、项目/文献笔记分组，保留文件夹数据与搜索/历史访问。
2. 笔记数据：新增经过校验的原文锚点、标签与 AI 摘录来源，备份升级，不改写已有正文。
3. 阅读与复习：共享文献笔记组件、可收起/调宽面板、标签状态保持、选区提问与摘录、原文精确定位。
4. 移动基础：手机抽屉与触控入口、平板分屏；原生运行、同步与发布依目标平台验证结果安排。
5. 验证、文档和版本更新：类型、构建、后端与浏览器流程测试，检查变更后本地提交。
6. GitHub：仅发布到用户确认的目标仓库，不推送原作者 upstream；源码与发行产物分开处理。

页面按现有深色色板与字体，采用项目资料夹与阅读工作台结构；复用已有边框与强调色，以布局层级体现首页、资料整理与阅读的差别。

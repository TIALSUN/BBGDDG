# iPhone / iPad 落地路线

用户已选定 iPhone / iPad 为移动优先平台。

## 当前交付：共用交互基础

手机主内容与 AI/笔记抽屉切换，平板分屏；触控选区、文献笔记、稳定锚点和草稿保存共用桌面数据接口。浏览器 390×844 和 1024×1366 尺寸流程验证不等同于 iOS 真机测试。

现有应用依赖桌面本机 Node/SQLite 服务且只监听回环地址。当前产物不能直接在 iPhone 上独立使用，不将移动布局当作 iOS 安装版。

## 下一阶段：运行与存储验证

比较独立移动运行（本地文献、SQLite/文件存储与 API 问答）和可达的远端服务方案。验证 iOS 文件选择、PDF 性能、Safari/WKWebView 选区、后台恢复、文件持久化与离线编辑。现有桌面 CLI AI 登录不能直接沿用到手机。

选择应用封装或移动网页路线前，以真机完成项目 → 导入 PDF → 阅读 → 提问 → 记笔记 → 复习定位。原生打包和签名需要可用的 macOS/Xcode 环境与开发者配置。

## 后续：同步与分发

确定文献和笔记存储位置、账户、同步冲突策略与离线更新。共享文献标识、内容标识与 PDF 坐标，不使用桌面绝对路径。技术验证通过后准备测试分发；正式上线日期在运行、同步与签名条件确定后排定。

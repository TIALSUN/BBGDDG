# iPad 手写验证记录

日期：2026-10-11。开发分支：feat/ui-ipad。当前为待真机验收的开发版本，不是正式 iPad 发布。

## 设备与访问

用户设备：用户描述为“最新款 Air，11 英寸”。具体代次、iPadOS、Safari 与 Pencil 型号尚未确认。
真实设备不在当前执行环境，以下真机项目均未验证：Pencil 连续书写延迟、手掌误触、手指滚动、双指缩放、旋转、软键盘、系统分屏、中断恢复、保存到“文件”再导入。
服务保持原有本机监听与会话认证。未开放局域网或公网端口；跨设备安全访问方式仍待确定。

## 已有自动验证证据

- UI：390 / 820 / 1024 像素代表性窗口，工具切换保留草稿、窄屏抽屉焦点、复习原文切换、导航及搜索状态。
- 增量升级：schema 10 → 11，升级前数据库备份包含旧笔记，旧正文保持不变。
- PDF：native PDF 坐标保存，缩放、重载不改变坐标；缩放撤销问题由新回归测试发现并修复。
- 笔记：手写块与 Markdown 共存，空白 / 横线 / 方格、延长纸张、套索复制 / 移动 / 缩放 / 删除、整笔擦除及撤销。
- 恢复：失败待重试、刷新恢复、本机与服务器冲突副本、明确采用服务器版本；已保存缓存不遮蔽服务器的新版本。
- 选区：显式 Pencil 文字工具，选字后仍需用户点击高光 / 注释 / 提问；单页 PNG 区域摘录、来源引用、跨项目拒绝访问、笔记删除清理无引用图片。
- 导出：pdf-lib 1.17.1 MIT，原文件 hash 不变、页数不变、旋转和 CropBox 保留；旋转裁切 fixture 栅格化校验标记位置及透明度，见 pdf-export-rotation.png。
- 笔记打印：中文、KaTeX、SVG 手写进入同源打印页，使用系统“存储为 PDF”；最终打印分页及字体需真机复核。
- 备份：含笔记、标注、可编辑笔迹及图片，不含原 PDF、密钥或数据库。重复恢复去重，错误路径、版本、校验及缺失引用拒绝，事务失败回滚。
- 性能：Chromium 桌面、1000 笔 × 100 点；单独运行 p95 4.80 ms，完整回归并发运行 p95 9.90 ms。仅测量活动输入到下一帧，不包含 Pencil 硬件延迟，也不是 iPad 性能认证。

## 实施决策与限制

1. 复用既有 SQLite / Fastify / React，新增 ink 文档，不修改原 PDF 或 Markdown。
2. 图片存 SQLite BLOB，避免裸文件路径；代价是数据库备份增大。
3. 几何引擎以纯 Node 测试代替浏览器动态导入，交互另用真实 Chromium E2E。
4. 备份 ZIP 使用 stored 条目，恢复仅接受本应用格式、不接受外部重新压缩的文件；限制压缩包 100 MiB、条目 10000、单图片 5 MiB，并校验 CRC / SHA-256 与结构。无需向文件系统解压，事务直接写 BLOB。代价是备份文件较大及外部重压缩不兼容。
5. 缺失原文的 PDF 手写恢复为独立笔记副本，保留原来源 ID / hash 提示，坐标转为笔记画布；不绑定另一份文献。代价是需重新导入原文后人工核对。
6. 首轮绘制使用选定固定粗细；压力值保存于笔迹中。真实压力笔刷、局部擦除、OCR、手写识别、形状辅助及高级 Pencil 操作均未宣称交付。
7. IndexedDB 是当前浏览器的待同步草稿存储，不等同完整离线文献库或跨设备同步。
8. 最终整套测试与独立审查结果在完成后补记；当前桌面固定入口及 Release 未替换。

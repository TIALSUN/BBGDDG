## 目标与约束

参考 Designeer 收录的界面资源，围绕“找文献 → 阅读 → 提问 → 记录 → 复习”重构 BBGDDG。保持中文深色风格，兼顾 Windows 桌面、iPad 横竖屏与系统分屏。

保留现有文献、笔记、标注、阅读进度和 AI 配置。数据库升级前备份，采用增量迁移，不清空个人数据。现有首页优化已实现；本文其余内容为拟议方案。

## 页面与流程

### 首页

保留并完善继续学习、项目搜索、项目列表、新建项目。增加一致的加载、空白、失败重试状态，统一导航与图标。

### 项目工作区

文献、笔记、标注、对话采用同一套导航。项目搜索与添加文献固定在顶部；保留文件夹、批量导入和导入进度。打开文献后返回项目时保留原列表上下文。

### 阅读页

中央原文，右侧 AI / 笔记 / 标注，辅助内容按需展开。顶部区分文档操作和标注工具，常用操作直接可见。保留专注阅读、阅读进度、引用跳转和原文临时标亮。

### 笔记

分开笔记列表和内容编辑。区分项目笔记与文献笔记。支持文字块、手写块与原文摘录；文字块保留 Markdown、公式、标签及明确保存操作。手写块提供空白、横线、方格背景和扩展高度。

### AI

统一模型选择、配置与状态。明确显示选中文字 / 当前文献 / 项目文献范围。回答提供核查原文和摘入笔记入口；手写、截图或识别内容仅在用户明确触发后交给 AI。保留既有记忆与用量功能。

### 设置

按阅读与标注、AI、数据与备份、应用信息分组。配置状态与可执行动作相邻。支持左手布局、工具栏位置、手指绘制开关等偏好。

## 视觉与组件系统

- 背景 #15171C，面板 #1D2027，边框 #343944，强调色 #788BEA，正文 #EDF0F7，辅助文字 #ABB3C3。
- 中文优先系统字体；正文、标题、辅助信息采用统一字号与行高。
- 间距采用 4 / 8 / 12 / 16 / 24 / 32 像素尺度；圆角随组件层级区分。
- 统一 SVG 图标、按钮、输入框、标签页、菜单、弹窗、抽屉与状态反馈。
- 控件包含悬停、选中、禁用、键盘焦点与加载状态。颜色之外提供文字或图标说明。
- 触控目标至少 44 × 44 CSS 像素；尊重减少动态效果设置。

## iPad 操作

### 布局

横屏默认原文与工具面板并排，分隔线可拖动，并提供可点击的宽度调整方式。竖屏原文优先，底部提供 AI / 笔记 / 标注入口。系统分屏根据实际可用宽度切换，空间不足时使用单栏与工具抽屉。

软键盘弹出时，当前编辑区和保存操作可见。面板切换、屏幕旋转、缩放和返回引用均保留阅读位置与草稿。左手模式可调整工具栏位置。

### 手指与 Pencil 分工

默认 Pencil 书写、手指浏览、双指缩放；可显式开启手指绘制。书写、文字选择、套索和区域框选是明确独立的工具模式，界面持续显示当前模式。

采用笔输入识别、输入区域限制和手势协调降低误触，不承诺网页具备系统级掌拒。笔输入中断时结束或撤销未完成笔画，不保存跨页飞线。

外接键盘支持搜索、保存、撤销 / 重做和关闭面板；文字输入期间避免全局快捷键冲突。Pencil 双击、挤压与悬停按平台能力检测，始终提供屏幕按钮替代。

## 手写与标注

### PDF

支持自由笔、自由荧光笔、下划线、橡皮擦、套索、颜色与粗细。可选中文字的 PDF 提供贴合文字的高光和下划线；扫描 PDF 首轮提供自由画线、荧光笔和区域截图，不伪装成可选择文字。

笔迹绑定文献内容标识、PDF 页序号和页面坐标；以统一的页面坐标及变换处理缩放、旋转和不同尺寸，不以当前屏幕像素作为永久位置。

### 笔记

手写块保存可编辑笔迹，支持移动、复制、删除与缩放。文字和手写有明确边界，混排不破坏现有 Markdown 内容。首轮采用可扩展的块画布；无限画布不纳入首轮。

### Pencil 选择

- 文字选择：拖选原文后复制、高光、创建笔记或问 AI。
- 套索：选择已有笔迹，移动、复制、删除、调整大小。
- 区域框选：截取公式、图表或图片，写入带文献和页码来源的笔记；OCR / AI 分析是独立动作。

### 编辑与恢复

首轮支持整笔擦除、撤销 / 重做。删除可撤销。局部擦除与形状辅助随后增加。

手写自动保存，显示保存中 / 已保存 / 失败待重试；保留本机待保存数据，失败后可恢复。文字笔记继续明确点击保存。混合笔记中分别说明正文草稿与手写保存状态，避免误认为整篇已保存。

修改原文文件后，如果内容标识变化，提示标注可能不适配；不静默绑定至新内容。

## 查找、复习与导出

标注按页码、颜色、类型过滤，可隐藏手写或高光查看原文。原文批注与笔记互相跳转，查看引用后可返回之前位置。

导出带标注 PDF、含文字与手写的笔记 PDF，并备份可编辑笔迹数据。默认另存副本。首轮 PDF 导出允许将标注合并为可见页面内容；在外部阅读器中继续编辑标准 PDF 注释属于后续独立能力。

## 数据与兼容

新增笔迹 / 画布数据采用版本化结构；包含所属文献页或笔记块、坐标、路径点、工具、颜色、粗细及可用压力信息。压力缺失时使用固定粗细。图片附件与笔迹数据分离存储，通过稳定标识引用。

PDF 原始文件不直接修改。新旧标注可共存，旧笔记可正常打开编辑。保存冲突不能静默覆盖，应保留冲突副本或提示处理。详细存储格式、接口和迁移步骤在实施计划中确定。

## 分阶段实施

1. 统一视觉与共用组件，重构项目导航、阅读布局、笔记列表及 AI 入口；验证现有流程。
2. 实现 PDF / 笔记手写、整笔橡皮擦、撤销重做、Pencil 选择、套索、框选及保存恢复；完成 iPad 真机验证。
3. 完成标注管理、来源往返、带标注导出、可编辑备份与旧数据升级验证。
4. 后续增强：OCR、手写转文字与搜索、局部擦除、形状辅助、受支持的 Pencil 高级交互。

每阶段交付可运行版本、截图与验证结果。只有核心手写链路和数据恢复验证完成，才将其描述为可日常使用。

## 平台边界

当前产品依赖 Windows 本机服务。iPad 页面可用不等于已有安全的 iPad 访问方案。首轮页面验证可使用隔离测试环境；正式 iPad 交付前必须确定安全访问与认证方式。

独立 iPad App、PencilKit 原生集成、完整离线使用、跨设备同步均是后续平台工作，不能仅靠响应式前端交付。首轮本机草稿恢复不等于多设备同步或完整离线文献库。

## 验收

- 旧项目、文献、笔记、标注、AI 设置和阅读进度可继续使用，升级前备份可恢复。
- 首页到文献、选区到笔记、AI 引用到原文及返回均可完成；失败反馈有下一步。
- Windows 鼠标键盘和 iPad 触控都能完成主要操作，没有仅悬停可用功能。
- iPad 真机覆盖可用的 Pencil / iPadOS / Safari 组合，记录设备型号和版本；至少验证横屏、竖屏、窄分屏及软键盘。
- 笔迹在缩放、旋转、滚动、重开后对齐；跨页书写不串页，手指滚动不意外画线。
- 可选文字 PDF 和扫描 PDF 分别验证；文字选择、套索、框选互不混淆。
- 中断输入、保存失败、刷新及服务重启后不将未保存内容误报为已保存；可恢复待保存笔迹。
- 导出内容无缺页、错位和裁切，原 PDF 不变，备份可恢复可编辑笔迹。
- 构建、相关自动化回归及真实设备手写检查通过。桌面浏览器模拟不能替代 Pencil 真机验收。

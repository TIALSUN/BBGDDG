# BBGDDG 1.0.0 本地验证记录

验证环境：Windows x64，Node.js 24.19.0，系统 Edge（Chromium）及 Electron 44.5.1。

## 已通过

- 完整后端测试：72 项；总体行覆盖率 86.18%，满足项目原有门槛。
- 完整浏览器测试：26 项，包括中文导航、项目、笔记、论文搜索、文献导入与阅读进度恢复。
- 干净 Git 克隆：没有依赖目录或目录联接，执行 npm ci 完成安装与前后端构建；typecheck 通过；另有 17 项 PDF 与编译后 CLI 测试通过。
- Electron 开发运行及打包后的 BBGDDG.exe：本机服务、原生 SQLite、PDF 导入、高亮位置、注释持久化、取消高亮、页面隔离与关闭服务通过。
- 模拟 API 原生测试：8 个服务选项、Windows 密钥保护、加密设置、问答用量、重启持久化及 AI 子进程环境隔离通过。真实服务商请求数为 0。
- Windows 安装版与便携版已生成。本轮未替换已安装的 PDFPal，未迁移其个人数据库。
- 当前源码没有真实密钥、账号文件或个人文献；唯一提交的 PDF 是上游测试夹具。源码归档由 Git 提交生成，依赖和运行数据不进入归档。

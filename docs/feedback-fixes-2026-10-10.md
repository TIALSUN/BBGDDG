# 阅读体验反馈：第一轮修复

本轮修复已有流程中的四项问题：文献集创建、公式显示、停止生成，以及跨文献切换时问答状态保留。

- 文献集使用应用内表单，提供创建中、失败与重试反馈，失败保留输入。
- AI 回答和笔记预览统一接受 `\(...\)`、`\[...\]` 与原有美元符号公式；转换仅用于展示，不改写保存的笔记正文，并跳过代码片段。
- 问答请求由文献对应的独立任务状态管理。应用内切换文献不取消请求，切回后显示进行中的问题或已完成回答。完整页面刷新、退出程序后的运行中任务恢复不在本轮范围内；已完成回答继续由数据库保存。
- 停止按钮通过 AbortController 取消浏览器请求，服务端在连接断开时向模型 HTTP 请求或 CLI 子进程传递取消信号。服务商是否停止远端计算及如何计费由服务商决定。
- 取消后保留问题供重试，不把未完成回答写入聊天历史或推进自动记忆。

没有数据库迁移，没有修改或清理用户文献、笔记、阅读进度及账号设置。

验证：服务端 TypeScript 构建、前端 TypeScript 检查及 Vite 构建通过；13 项相关后端测试通过，包含真实 HTTP 断开后上游连接关闭及无回答落库；10 项浏览器回归测试通过，包含禁止 window.prompt 后创建文献集、创建失败保留名称、回答与笔记公式渲染、跨文献任务保留及停止生成。

扫描件 OCR、图片上下文、多模型配置、阅读面板放大和在线导入失败引导仍待后续处理。本轮为源码修复，尚未生成新的正式安装包或替换正在运行的桌面程序。
